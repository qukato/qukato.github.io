2. 段落和换行#

  • 段落之间用空行分隔。
  • 在行尾添加两个或更多空格可以强制换行。

3. 强调#

  • 加粗：使用 ** 或 __ 包裹文本。
  • 斜体：使用 * 或 _ 包裹文本。
  • 删除线：使用 ~~ 包裹文本。

4. 列表#

  • 无序列表：使用 -、* 或 + 开始每一项。
  • 有序列表：使用数字加点开始每一项。
